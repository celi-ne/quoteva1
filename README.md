# Quoteva — اقتباسات ملهمة وآمنة

نسخة Frontend تفاعلية باللغة العربية واتجاه RTL، مستوحاة من الصورة المرجعية المرفقة. لا تحتاج إلى قاعدة بيانات أو مفاتيح API، وتعمل بالكامل داخل المتصفح مع حفظ الوضع والمفضلة والاقتباسات المضافة في `localStorage`.

## التشغيل السريع

### الطريقة الأولى: عبر Node.js

1. ثبّت Node.js 18 أو أحدث.
2. افتح الطرفية داخل مجلد المشروع.
3. شغّل:

```bash
npm start
```

4. افتح `http://localhost:3000` في المتصفح.

### الطريقة الثانية: بدون Node.js

إذا كان Python مثبتًا لديك:

```bash
python3 -m http.server 3000
```

ثم افتح `http://localhost:3000`.

كما يمكن فتح `index.html` مباشرة بالنقر المزدوج، لكن تشغيل خادم محلي يعطي تجربة أدق لميزات المشاركة والنسخ.

## التخصيص

- عدّل الاقتباسات الأولية داخل `app.js` في المصفوفة `seedQuotes`.
- عدّل الألوان والخطوط والمسافات داخل `styles.css` من متغيرات `:root`.
- غيّر صورة الـHero في `public/assets/hero-scene.jpg` أو حدّث مسارها في CSS.
- أي اقتباس جديد أو إعجاب أو إعداد للمظهر يحفظ محليًا في المتصفح، ويمكن مسحه من إعدادات الموقع في المتصفح.

## بنية الملفات

- `index.html`: بنية الصفحة العربية.
- `styles.css`: النظام البصري والاستجابة للشاشات.
- `app.js`: البيانات والتفاعلات والنوافذ المنبثقة.
- `server.mjs`: خادم ملفات محلي بلا اعتماديات خارجية.
- `public/assets/`: الشعار وصورة المشهد المستخدمة في التصميم.


## صفحات الحساب المضافة
- `/login.html`: صفحة تسجيل الدخول.
- `/signup.html`: صفحة إنشاء حساب.
- تمت إضافة روابط الحساب إلى الهيدر.
- هذه الصفحات واجهات تجريبية للتحقق من الحقول فقط؛ لم يتم ربطها بمصادقة حقيقية أو قاعدة بيانات. اربطها بـ Supabase قبل استخدام حسابات فعلية.
